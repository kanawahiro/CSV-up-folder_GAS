# CSV-up-folder_GAS 実装計画書

## 概要

Google Drive の `input` フォルダにCSVを置くだけで、対応する子GASへ自動振り分け・取込を行う親GAS。
複数のCSV種別を一元管理し、処理結果をログスプレッドシートに記録する。

---

## システム構成

```
[ユーザー]
  ↓ CSVをアップロード
[Drive: input フォルダ]
  ↓ 5分毎のポーリング
[親GAS: CSV-up-folder_GAS]
  ├── ファイル名プレフィックスで振り分け
  │     ├── act_    → 楽天サーチ子GAS (raku_sa-chi_GAS)
  │     └── (将来追加)
  ├── 取込成功 → [Drive: processed フォルダ] へ移動
  ├── 取込失敗 → [Drive: error フォルダ] へ移動
  └── 結果を [ログスプレッドシート: log シート] に記録
```

---

## 必要なリソース（事前に作成が必要なもの）

| リソース | 種類 | 用途 |
|--------|------|------|
| `input` フォルダ | Google Drive フォルダ | CSVの投入口 |
| `processed` フォルダ | Google Drive フォルダ | 成功ファイルの保管 |
| `error` フォルダ | Google Drive フォルダ | 失敗ファイルの保管 |
| ログスプレッドシート | Google スプレッドシート | 処理結果の記録 |
| 親GASプロジェクト | Google Apps Script | このGASのデプロイ先 |

---

## 実装ステップ

### Step 1: Googleリソースを手動作成する

1. **Driveフォルダ作成**
   - `input` / `processed` / `error` の3フォルダを作成
   - 各フォルダをブラウザで開き、URLからフォルダIDをメモ
     ```
     https://drive.google.com/drive/folders/【このIDをメモ】
     ```

2. **ログスプレッドシート作成**
   - 新規スプレッドシートを作成
   - シート名を `log` に変更
   - 1行目にヘッダーを手入力:

     | A | B | C | D | E |
     |---|---|---|---|---|
     | 実行日時 | ファイル名 | status | 取込件数 | メッセージ |

   - スプレッドシートのURLからIDをメモ
     ```
     https://docs.google.com/spreadsheets/d/【このIDをメモ】/edit
     ```

3. **GASプロジェクト作成**
   - [script.google.com](https://script.google.com) で新規プロジェクトを作成
   - プロジェクト名を `CSV-up-folder` などに設定
   - 「プロジェクトの設定」からスクリプトIDをメモ

### Step 2: 定数を設定してコードをデプロイする

メモしたIDを `src/コード.js` の定数部分に設定してもらい、`clasp push` でデプロイ。

```
LOG_SPREADSHEET_ID  ← ログスプレッドシートのID
DRIVE_FOLDERS.input / processed / error  ← 各フォルダのID
CHILD_SCRIPTS       ← 子GASのプレフィックスとスクリプトIDを登録
```

### Step 3: 子GAS側の準備（raku_sa-chi_GAS）

子GASをWebアプリとしてデプロイし、HTTPリクエストを受け取れるようにする。

- `doPost(e)` 関数を追加してWebアプリのエンドポイントを作成
- GASエディタからデプロイ → 「ウェブアプリ」として公開
- デプロイされたスクリプトIDを親GASの `CHILD_SCRIPTS` に登録

### Step 4: トリガーを設定する

GASエディタで `setupTrigger` を一度だけ手動実行する。
→ 5分毎のポーリングトリガーが自動登録される。

### Step 5: 動作確認

`input` フォルダに実CSVをアップロードし、5分以内に以下を確認する。

- [ ] `processed` フォルダにファイルが移動している
- [ ] ログスプレッドシートに結果が記録されている
- [ ] 子GASのスプレッドシートにデータが取り込まれている
- [ ] エラー時は `error` フォルダに移動している

## 今後の拡張方針

新しいCSV種別を追加するときは以下の2点だけ対応する。

1. 子GAS側に `doPost(e)` + `importFromFileId(fileId)` を実装
2. 親GASの `CHILD_SCRIPTS` にプレフィックスとスクリプトIDを1行追加
