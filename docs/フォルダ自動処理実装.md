# CSV自動取込 フォルダ自動処理実装計画

## 概要

Google Drive の `01input` フォルダにCSVを入れるだけで、ファイル名のプレフィックスに応じた子GASへ自動振り分けを行う構成。

---

## GAS構成

| GAS名 | 役割 | GAS URL |
|---|---|---|
| アップ用親フォルダGAS | フォルダ監視・振り分け | https://script.google.com/u/0/home/projects/1pObElCJbDz9GIUZZmZjTZhEPa2DLqai9nstUcNONY47i5624CQ16xOow/edit |
| 楽天サーチ 記録用 | 楽天サーチCSV取込 | https://script.google.com/home/projects/1beZAm8T7sp5LVwlQhGA4p9lLtdq3uZErKW6AHgW45Os3gCULEEnBOsKr/edit |

---

## 処理の流れ

```
[ユーザーがCSVを 01input に置く]
  ↓ 1分おきにポーリング
[アップ用親フォルダGAS]
  ├── ファイル名が act_ で始まる → 楽天サーチ 記録用（ウェブアプリ）へ POST
  └── 該当なし → 03error へ移動・ログに記録
  ↓
[楽天サーチ 記録用（doPost）]
  └── importFromFileId(fileId) → スプレッドシートに書込 → 結果を返す
  ↓
[親GAS]
  ├── 成功 → 02processed へ移動
  └── 失敗 → 03error へ移動
  └── ログスプレッドシートに記録
```

## 実装内容

### 親GAS（アップ用親フォルダGAS）への追加・変更

**変更ファイル**: `CSV-up-folder_GAS/src/コード.js`

1. **定数を実値に設定**（現在はプレースホルダー）
   - `DRIVE_FOLDERS` の各フォルダID
   - `LOG_SPREADSHEET_ID`
   - `CHILD_SCRIPTS` にプレフィックスとウェブアプリURLを登録

2. **`dispatchToChild_` の変更**
   - `scriptId` 方式 → `webAppUrl` 方式に変更
   - `webAppUrl` が空の場合、クラッシュせず `error` を返す

3. **`logResult_` の改善**
   - `log` シートが存在しない場合、自動作成＋ヘッダー行を挿入

4. **`setupTrigger` の変更**
   - 5分 → 1分ごとのトリガーに変更

5. **`.clasp.json` のscriptIdを設定**
   - `YOUR_SCRIPT_ID` → `1pObElCJbDz9GIUZZmZjTZhEPa2DLqai9nstUcNONY47i5624CQ16xOow`

### 子GAS（楽天サーチ 記録用）への追加

**変更ファイル**: `raku_sa-chi_GAS/src/コード.js`

1. **`doPost(e)` を追加**
   - 親GASから `{ fileId }` を受け取り `importFromFileId(fileId)` を実行
   - 結果をJSON形式で返す

2. **`triggerMinutes` を 1 → 5 に戻す**
   - フォルダ監視トリガーは親GASに移行するため

## セットアップ手順（実装後に行う手動作業）

1. **子GASをウェブアプリとしてデプロイ**
   - 楽天サーチ 記録用 のGASエディタを開く
   - デプロイ → 新しいデプロイ → 種類: ウェブアプリ
   - 実行者: 自分、アクセス: 全員（URLを知っている人）
   - デプロイURLをコピー（`https://script.google.com/macros/s/AKfycbx.../exec`）

2. **親GASの `CHILD_SCRIPTS` にURLを設定して再push**
   ```javascript
   const CHILD_SCRIPTS = [
     { prefix: 'act_', webAppUrl: 'ここにデプロイURL', desc: '楽天サーチ取込 (楽天サーチ 記録用)' },
   ];
   ```

3. **親GASエディタで `setupTrigger()` を手動実行**（1分トリガーが登録される）

4. **旧トリガーの削除**
   - 楽天サーチ 記録用 のGASエディタ → トリガー一覧 → `processInputFolder` のトリガーを削除

## テスト観点

- `act_` で始まるCSVを `01input` に置く → 取込後 `02processed` に移動すること
- ログスプレッドシートの `log` シートに `success` と取込件数が記録されること
- プレフィックスなしCSVは `03error` に移動し `振り分けルールが未設定` と記録されること
- `webAppUrl` が空のままでも `ウェブアプリURLが未設定` エラーのみで止まらないこと
- `setupTrigger()` を再実行しても `processInputFolder` のトリガーが重複しないこと

---

## 将来の拡張方法

新しいCSV種別を追加するときは以下の2つだけ対応する：

1. **子GASに `doPost(e)` + `importFromFileId(fileId)` を実装してウェブアプリとしてデプロイ**
2. **親GASの `CHILD_SCRIPTS` に1行追加**
   ```javascript
   { prefix: '新しいプレフィックス_', webAppUrl: 'デプロイURL', desc: '説明' },
   ```
